# ☕ Estudos Java

Este repositório guarda os meus projetos e exercícios práticos de nivelamento e aprendizado na linguagem **Java**. Ele serve como um diário do meu progresso, desde os conceitos mais básicos de sintaxe até a resolução de algoritmos, ajudando a consolidar meus conhecimentos práticos e servir de base para treinamentos intensivos, como o bootcamp GFT Start #7.

## 📁 Estrutura do Repositório

Cada pasta neste diretório é um mini-projeto focado em um conceito ou grupo de exercícios específicos:

*   **`primeiro_projeto/`**: O pontapé inicial, testes de ambiente e comandos básicos de saída.
*   **`entradaDeDados/`**: Práticas de leitura de dados do teclado interagindo com o usuário (uso da classe `Scanner`).
*   **`funcoesMatematicas/`**: Exercícios aplicando métodos da classe `Math` (raízes, potências, arredondamentos, etc).
*   **`atividadeFixacao1/`**: Prática geral para fixar os conceitos de declaração de variáveis e formatação de texto.
*   **`exEstruturaSequencial/` a `exEstruturaSequencial6/`**: Uma bateria de exercícios para treinar a lógica de programação usando estrutura sequencial pura (entrada, processamento e saída).

## 🛠️ Tecnologias e Ferramentas

*   **Java** (Linguagem de programação principal)
*   IDE (Utilizada para escrever, compilar e rodar os códigos)
*   **Git e GitHub** (Para controle de versão e backup)
